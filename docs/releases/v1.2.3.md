# GigBuddy v1.2.3

Released 2026-08-14.

## Fixed

The one-line installer now prints the complete output of a failed command,
instead of retaining only its last 40 lines. Its error header includes the
failed command and its original exit status. This makes bootstrap, virtual
environment, and preset-download failures diagnosable from the terminal
output alone.
