# GigBuddy v1.2.1

Released 2026-08-14.

## Fixed

The user installer now upgrades an existing GigBuddy checkout created from an
old release tag. Earlier shallow tag clones could retain a remote fetch refspec
for a retired tag such as `v1.1.1`; a normal update then failed before it could
check out the requested release. The installer now explicitly fetches the
remote's available tags, so a stale legacy refspec cannot block the update.

## Validation

- A regression test creates a checkout with the retired `v1.1.1` fetch refspec
  and verifies that the installer fetch form retrieves `v1.2.1` successfully.
- Focused installer and library tests pass under the configured project test
  path. The full suite is unchanged from `v1.2.0` and was not rerun for this
  installer-only patch.

The Tone Pack and shareable Preset workflows introduced in
[v1.2.0](v1.2.0.md) are unchanged. Their full user guide remains
[GigBuddy tone file management](../tone-file-management.md)
([中文](../tone-file-management.zh-CN.md)).
