# GigBuddy v1.2.2

Released 2026-08-14.

## Fixed

TONE3000 model display names are no longer treated as filenames when they end
in a decimal value, such as `G5.0` or `0.25in`. GigBuddy now continues to the
actual model URL to identify the `.nam` or `.wav` asset. This restores starter
Preset bootstrap for the Gallien-Krueger RB800 A2 model and the Marshall
1960TV Greenback IR, and fixes the same classification error for other models
with decimal-valued labels.

## Validation

- ` .venv/bin/python -m pytest tests/test_tone3000_api.py `: 60 passed.
- The live TONE3000 API resolves model `419198` as A2 and model `656897` as
  an IR after the classifier change.
